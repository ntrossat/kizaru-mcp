# Security

kizaru-mcp is an OAuth server that holds users' Lightdash tokens, so security reports are welcome.

## Report a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/ntrossat/kizaru-mcp/security/advisories/new), not in a public issue. Include the steps to reproduce it and the version or commit.

## Supported versions

Fixes go into `main`.

## Deployment

See [Configuration](docs/configuration.md#run-it-publicly) for what a public deployment needs.
